# MY_HOME - Система управления устройствами умного дома

## Описание

MY_HOME - это комплексная система управления устройствами умного дома, состоящая из веб-интерфейса на Vue.js и бэкенда на FastAPI. Система предназначена для мониторинга, управления и автоматизации различных устройств в домашней сети.

## Основные возможности

- 🔍 **Сканирование сети** - автоматическое обнаружение устройств в локальной сети
- 📊 **Мониторинг устройств** - отслеживание состояния и параметров устройств
- 🎛️ **Управление устройствами** - удаленное управление через веб-интерфейс
- 📈 **Визуализация данных** - графики и диаграммы для анализа данных
- 🔄 **Real-time обновления** - WebSocket соединения для мгновенных обновлений
- 📱 **Адаптивный интерфейс** - современный UI на Vuetify
- 🔐 **Безопасность** - интеграция с Home Assistant API

## Архитектура

### Backend (FastAPI)
- **Веб-сервер**: FastAPI с поддержкой WebSocket
- **База данных**: SQLAlchemy ORM
- **Сканирование сети**: SSDP протокол для обнаружения устройств
- **Интеграции**: Google Sheets API, MQTT, Home Assistant
- **API**: RESTful API для управления устройствами

### Frontend (Vue.js)
- **Фреймворк**: Vue 3 с Composition API
- **UI библиотека**: Vuetify 3
- **Состояние**: Pinia для управления состоянием
- **Маршрутизация**: Vue Router
- **Графики**: Chart.js для визуализации данных
- **Сборка**: Vite

## Установка и запуск

### Требования
- Python 3.8+
- Node.js 16+
- Docker (опционально)

### Локальная разработка

#### Backend
```bash
cd my_home/backend
pip install -r requirements.txt
uvicorn websrv:app --reload --host 0.0.0.0 --port 3000
```

#### Frontend
```bash
cd my_home/frontend
npm install
npm run serve
```

### Docker
```bash
cd my_home
docker-compose up -d
```

## Конфигурация

Основные настройки находятся в файле `config.yaml`:

```yaml
name: "MY_HOME-devices"
version: "0.0.4"
local_network: "192.168.0.1/24"    # Локальная сеть для сканирования
scan_timeout: 2                     # Таймаут сканирования
is_fast_scan: true                  # Быстрое сканирование
save_config_hour: 1                 # Период сохранения конфигурации

# Настройки для бэкапа - только папки данных (без Docker образа)
map:
  - data
  - data_src
```

### Настройка бэкапа

Для уменьшения размера бэкапа с ~600МБ до ~2МБ (исключение Docker образа) в `config.yaml` добавлен параметр `map`, который указывает Home Assistant включать в бэкап только папки данных.

Runtime-данные, базы, логи, токены и секреты не хранятся в репозитории и создаются на целевом Home Assistant.

## API Endpoints

### Основные маршруты
- `GET /api` - Проверка состояния сервера
- `GET /api/devices` - Список устройств
- `POST /api/devices` - Добавление устройства
- `PUT /api/devices/{id}` - Обновление устройства
- `DELETE /api/devices/{id}` - Удаление устройства

### WebSocket
- `ws://localhost:3000/ws` - WebSocket соединение для real-time обновлений

## Компоненты

### Backend компоненты
- **MyHomeClass** - Основной класс для управления системой
- **Device** - Модель устройства
- **GoogleConnector** - Интеграция с Google Sheets
- **SocketUtils** - Утилиты для WebSocket соединений

### Frontend компоненты
- **DeviceCard** - Карточка устройства
- **ConnectionCard** - Карточка соединения
- **LineChart** - График данных
- **StatusCard** - Карточка статуса

## Интеграции

- **Home Assistant** - Интеграция с системой умного дома
- **Google Sheets** - Экспорт данных в таблицы
- **MQTT** - Протокол для IoT устройств
- **SSDP** - Обнаружение устройств в сети

## Разработка

### Добавление нового устройства
1. Создать модель в `backend/models/device.py`
2. Добавить API маршруты
3. Создать Vue компонент в `frontend/src/components/devices/`
4. Обновить store для управления состоянием

### Добавление новых функций
1. Backend: добавить логику в соответствующий модуль
2. Frontend: создать компоненты и обновить store
3. Обновить API документацию
